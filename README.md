# Werdio Website

Next.js website for Werdio.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before publishing

1. Replace `YOUR_SUPPORT_EMAIL@example.com` in `app/page.js` and `app/privacy-policy/page.js`.
2. Replace the Google Play button URL in `app/page.js` with the exact Werdio Play Store URL.
3. Replace `public/app-ads.txt` with the exact line generated by AdMob.
4. Deploy to Vercel or another Next.js host.
5. Use the deployed URL as the developer website in Google Play Console.

## app-ads.txt

The final public URL must be:

`https://YOUR-DOMAIN/app-ads.txt`
